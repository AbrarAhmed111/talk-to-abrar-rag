## 13. GPS Route Simulation & Tracking System (`gps-tracker` & `gps-tracker-backend`)
- **Classification:** Production project
- **Category:** Full-Stack IoT / Fleet Telematics Simulation
- **Frontend Repository:** https://github.com/AbrarAhmed111/gps-tracker
- **Frontend Live URL:** https://gps-tracker-vert.vercel.app
- **Backend Repository:** https://github.com/AbrarAhmed111/gps-tracker-backend
- **Backend Live URL:** https://gps-tracker-backend-gules.vercel.app
- **Frontend Tech Stack:** Next.js, TypeScript, Tailwind CSS, Supabase (Authentication & User Roles), Interactive Map Engine
- **Backend Tech Stack:** Python 3, FastAPI, Pandas/OpenPyXL, Google Maps Geocoding API, Route Interpolation
- **Architecture & Workflow:**
  - A decoupled full-stack telematics system.
  - **FastAPI Backend:** Ingests route and waypoint data from spreadsheets (Excel), geocodes raw address strings via Google Maps Geocoding API, analyzes journey geometry, and serves real-time position simulation endpoints.
  - **Next.js Frontend:** Displays a live interactive map dashboard where dispatchers can monitor simulated vehicle routes, track waypoint progression, inspect vehicle telemetry, and manage role-based operator permissions via Supabase.
