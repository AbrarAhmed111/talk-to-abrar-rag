## What is HolidaysUnlocked?
HolidaysUnlocked is an end-to-end hotel booking platform and reservation marketplace. It provides travelers with streamlined hotel discovery, search, room availability checks, and reservations, while giving property hosts a dedicated portal to manage listings and guest bookings.

## The Problem It Solves
Hotels and independent lodging hosts require an intuitive, low-friction platform to publish properties, set rates, and manage bookings without exorbitant aggregator commissions, while travelers demand fast search and verified room reservation flows.

## What Abrar Ahmed Personally Built
Abrar built HolidaysUnlocked end-to-end from MVP discovery through production launch:
1. **Full-Stack Architecture:** Architected the entire platform on Next.js and MongoDB.
2. **Search & Inventory Modeling:** Designed schema relationships for properties, room tiers, seasonal pricing, and real-time reservation availability.
3. **Guest & Host Flows:** Built authentication, user accounts, search filters, reservation checkout, and host property listing tools.
4. **Host Dashboards:** Implemented administrative management dashboards for hosts to review incoming bookings, update availability, and manage guest communication.
